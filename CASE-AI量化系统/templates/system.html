系统状态 -- 使用说明

这个 Tab 是干嘛的

系统级运维面板：健康检查、定时任务、以及本机 MySQL 数据下载规划。

行情与交易工具

页顶先选再保存，写入 .env 的 WUCAI_QMT。 通达信只能历史数据和模拟盘，不能自动下单；QMT / miniQMT 才能实盘。 切过去若没连通会提示，不会自动改回。

选通达信后还有日线来源：默认 官网日线包（WUCAI_TDX_SOURCE=official）， 同步时读官网 _hsjdayinfo.js 并下载 hsjday.zip， 不用安装或打开通达信。也可切到 本机 vipdoc，只读客户端已经下好的盘后文件。

数据下载怎么跑

python app.py 会同时拉起调度器：到点采，启动时也会检查未下完/落后的表并后台续跑 （和本页「同步」同一套函数）。新闻/研报只在上次被掐断时续，其余到点再跑。 tdx + 官网日线包：15:40 同步前会先更新 vipdoc。 tdx + 本机 vipdoc：仍要自己在通达信里做盘后数据下载。

新闻、研报是全市场，会跑比较久；当日或近 7 天已采过的会跳过。

日K如果还不是前复权，页顶会提示。点「全量更新」整段重刷，大约几十分钟。刷完后每天的「同步」只追加，除权的股票才整段重下。

模拟盘 / 实盘

主循环在 app.py 进程里：启动时监控池不空就开模拟盘，/live 页也可手点启停。 调度器不在 15:00 停循环，A 股收盘后还要跑美股夜盘。实盘是 /live/real，同一套引擎。
