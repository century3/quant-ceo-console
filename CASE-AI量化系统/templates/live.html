实盘监控 -- 使用说明

本页负责自动跑策略循环 (约每分钟一轮): 拉行情 → 算信号 → 风控 → 下单。 默认模拟, 不会连券商。当前工具是 {{ qmt_backend }}。 {% if not can_trade %}通达信只能灌历史数据，模拟盘用日线收盘价，没有实盘下单。{% else %}选实盘前务必确认账户已登录。{% endif %}

怎么用 (三步)

  1. 左侧「实时持仓」点右上 + 添加股票, 输入代码并选策略 (如 MACD 日K), 确定后写盘并热加载。旁边「仓位管理」给股票分档、看目标金额。
  2. 需要切换某只股票的策略时, 直接点「实时持仓」表里的策略名即可弹窗切换。
  3. 点持仓里的代码 / 名称可弹出日 K 线图 (含均线与成交量)。
  4. 右侧「资金面板」头部即是引擎开关 -- 启动 / 停止; 持仓 / 信号 / 订单约 5 秒自动刷新。

监控列表从哪来

合并去重: mock 持仓 + watch_pool 列表 + 已绑定策略 (per_stock) 的代码; 「添加股票」会同时写 watch_pool 和 per_stock。 A 股 T+1: 当日买的次日才能卖, 策略按日 K 波段下单。

引擎控制 / 风控 / 应急

右侧「资金面板」头部带启动 / 停止按钮和状态徽章 (RUNNING / PAUSED / HALTED); 下方「重置模拟盘」会先弹出当前股票、策略、档位和起始日，确认后再按这套回放。 更下方「风控」卡片说明档位开仓 (已分档才买) 与亏 ≥2% 自动熔断; 最底部「应急干预」(暂停买入 / 一键清仓 / 强制熔断) 平时折叠, 黑天鹅时才打开。

进阶扩展

  • 兜底策略: 未在 per_stock 里指定的代码会走 config/strategies.yaml 的 default。
  • 批量编辑 / 临时代码: 直接改 config/watch_pool.yaml、config/strategies.yaml; 修改后调 POST /api/live/strategies/config 触发热加载。
  • 事件流: 每轮循环的耗时与信号数, 可在 GET /api/live/state 的 events 字段查看。
添加股票并绑定策略

写入监控列表与 strategies.yaml 并热加载；出买/卖信号时由主循环按该策略计算。

买入数量不由本弹窗填写：先在仓位管理里分档，有买点时按该档目标金额整手买入。未分档只监控、不开仓。
