复盘 & 策略管理 -- 使用说明

这个 Tab 是干嘛的

赚了是运气还是实力? 这个 Tab 用统计方法回答这个问题; 上线体检回答这套策略+这只股票该观察、加仓还是停。

三个子功能

  • Brinson 归因 -- 把超额收益拆成"配置效应 (赌赛道)" + "选股效应 (Alpha)" + "交互". 3 个数据源任选: 模拟盘成交 / 实盘交割单 / 演示数据. 顶部流水面板可以单独看订单 + 成本水位 (bps).
  • Walk-Forward 过拟合检测 -- 滚动训练/评估窗口, 暴露策略真实 OOS 表现, 上实盘前的核心检测
  • 策略生命周期 -- 按「策略 + 股票」体检: 继续观察 / 可以上实盘 / 建议停用. 只给建议, 不改仓位

典型场景

场景 1 (周末复盘): 跑 Brinson, 看本周赚的钱主要来自赌赛道还是选对股; 选股效应弱 → 多因子模型要调整

场景 2 (上线前过拟合体检): 新策略先在 Walk-Forward 里跑; OOS/IS ≥ 0.7 才放行, 否则压缩参数空间 / 换样本继续调

场景 3 (加仓还是停): 某一票的某一套策略, 模拟盘满 20 天、收益为正、回撤 < 5% → 可以上实盘, 先给约 5%; 回撤 > 20% → 这对本停

数据来源

  • Brinson 归因: 顶部"数据源"下拉支持三个选择
    • 模拟盘 (默认): 用 live_state.json 订单流水 (已平仓 + 期末未平仓盯市). A 股对照沪深300 + 申万一级; 美股只取 .US 成交, 行业用 trade_stock_us_status, 基准是除指数外的美股行业等权. 区间默认 2026-04-01 至今
    • 实盘交割单: 同一套成交口径, 数据来自券商「历史成交」CSV. 区间取文件名导出起止日 (如 260101-260325 → 2026-01-01 ~ 2026-03-25), 未平仓按截止日收盘盯市, 截止日之后的买卖不进这张单. QMT 只有现仓和当日成交, 不能当区间复盘
    • 演示数据: 教学构造的「AI 主线月」行业权重/收益, 不是真实持仓, 用来手算对照 BHB 公式
  • 申万一级字典: xtdata 拉取后缓存到 outputs/sw1_industry_map.json, TTL 7 天; 可点"刷新行业字典"立即更新
  • 上线体检: 模拟盘按当前路由回放 4 月 1 日以来的成交, 一票一套策略各算各的. 不评整户净值

Brinson 实现说明

  • A 股基准: 沪深300 行业内等权 (该行业有几只成分股 / 有效成分数, 不按市值加权)
  • 美股基准: trade_stock_us_status 里除「指数」外的股票, 按行业家数等权; 行情读 trade_stock_us_daily
  • 模拟盘 / 实盘都按区间内全部买卖进账 (已卖掉的票也复盘); 权重按累计买入金额; 未平仓按截止日期收盘盯市. CSV 默认区间是文件名导出起止日, 不是最后一笔成交日
  • 境外标的 (e.g. 513100.SH 纳指 ETF): 归到 "境外/其他" bucket, 进入"配置效应" (基准无此行业)
  • 基准区间收益: end 收盘 / start 开盘 - 1, 来自 MySQL trade_stock_daily

Walk-Forward 实现说明

  • 流程: 在每个时间窗口的训练期 (默认 120 天) 从候选参数里挑 Sharpe 最高的, 然后用这组参数在紧接的评估期 (默认 60 天) 跑 OOS, 滚动到下一段重复
  • 行情: A 股走原来的日 K。美股写 RKLB 或 RKLB.US，读 trade_stock_us_daily
  • 4 个内置策略: 双均线 (趋势) / 布林带反转 / RSI 反转 / 唐奇安通道突破 -- 覆盖经典三大风格
  • OOS/IS 比例: ≥ 0.7 相对鲁棒, 0.5~0.7 中度衰减, < 0.5 严重过拟合
  • 过拟合分数: (IS_Sharpe - OOS_Sharpe) / IS_Sharpe, < 30% 鲁棒 / 30~70% 中度 / > 70% 严重
  • 注意: 当 IS Sharpe ≤ 0 (策略训练期都不赚钱) 时 OOS/IS 与过拟合分数会被强制设为 0, 此时 verdict OK 是假阳性, 必须 IS > 0 + OOS/IS ≥ 0.7 才算真鲁棒
  • 典型经验: A 股个股 + 简单技术指标策略 (双参数级别) 几乎都会显示严重过拟合, 这是策略本身的局限. 真要找鲁棒策略需要换更复杂的模型 (多因子选股 / 风险平价 / 配对交易等)

上线体检实现说明

  • 一票一策略. 茅台上的 MACD 和纳指上的 MACD 分开算, 分母是这对本金 (峰值占用)
  • 模拟盘升小仓: 20 天 + 收益 > 0 + 回撤 < 5%; 回撤 > 20% 建议停这对本
  • 工具只给建议仓位 (0 / 5% / 30%), 不会改 /live 的真实仓位
  • 实盘成交没有我们的策略名, 所以这页只评模拟盘

归因结果
超额收益 = 配置效应 + 选股效应 + 交互效应. 配置 = 调高/调低某行业的权重赚到的钱; 选股 = 在某行业里挑出比基准更牛的股票赚到的钱; 交互 = 二者耦合.
这一张表就是演示的输入. 通信超配 30% vs 基准 5%, 基准涨 9.7%, 配置项会很大 -- 用来对照公式, 不是某个月的真实持仓.
